# Plan Académico LCC - Interactivo

Aplicación web interactiva para el seguimiento del plan de estudios de la **Licenciatura en Ciencias de la Computación (Plan 2022)**.

## 🚀 Ver en línea

El proyecto se encuentra publicado en GitHub Pages:
👉 **[https://martinvarela206.github.io/PlanDeEstudio/](https://martinvarela206.github.io/PlanDeEstudio/)**

## ✨ Características

- 📊 **Progreso en tiempo real**: Porcentaje de la carrera completado y título intermedio.
- 🎓 **Cálculo de Promedio**: Promedio académico general y sin aplazos.
- 🔄 **Gestión de Materias**: Marcar materias como aprobadas, regularizadas o pendientes con sus notas correspondientes.
- 🔗 **Control de Correlatividades**: Verificación de requisitos para cursar y rendir cada materia.
- 🌙 **Modo Oscuro / Claro**: Interfaz adaptable a la preferencia del usuario.
- 💾 **Persistencia Local**: Guardado automático en el navegador mediante `localStorage`.

## 🛠️ Tecnologías

- HTML5 / CSS3 (CSS Vanilla con variables y diseño responsive)
- JavaScript Vanilla (ES6+)
- Lucide Icons
